# Floe — мем-токены на TON (мини-апп для Antarctic Wallet)

Некастодиальный лаунчпад мем-токенов: создание токена с настраиваемыми свойствами, торговля по bonding curve и свечные графики.
**Без сервера:** контракты на FunC, фронтенд — статика на GitHub Pages, данные читаются прямо из блокчейна.

**Сайт:** https://gru2007.github.io/floe/ · **Antarctic:** https://aw.me/app/29027654

Скрытый выбор testnet/mainnet открывается 7 нажатиями на логотип Floe или по `#/settings`. Подробности о запуске фабрики и настройках для всех пользователей: [DEPLOYMENT.md](DEPLOYMENT.md).

```
┌──────────────────────┐   postMessage   ┌──────────────────────────────┐
│ Antarctic Wallet     │◄───────────────►│ Floe (статический сайт,      │
│ (iframe / WebView)   │  aw-sdk: тема,  │  GitHub Pages)               │
└──────────────────────┘  назад, QR,     │                              │

┌──────────────────────┐   TON Connect   │  пишет: TON Connect          │
```

## Что внутри

| Путь | Что это |
|---|---|
| `contracts/factory.fc` | Фабрика: валидирует параметры, разворачивает токен по адресу `(factory, index)`, берёт плату за создание |
| `contracts/token.fc` | Jetton master (TEP-74/64/89) со встроенной кривой. **Нет админа и mint** — токены выпускаются только при покупке |
| `contracts/jetton-wallet.fc` | Стандартный кошелёк без ограничений переводов; `burn` = продажа кривой (с защитой от проскальзывания) |
| `shared/protocol.ts` | Опкоды, математика кривой (1-в-1 с FunC), сборка сообщений, TEP-64 метаданные, парсеры storage — общая для тестов и фронта |
| `tests/Floe.spec.ts` | 13 sandbox-тестов: создание, покупка/продажа, рефанды, лимиты, комиссии, платёжеспособность при 60 случайных сделках |
| `app/` | Мини-апп (React + Vite): главная, создание, страница токена с графиком и торговлей, портфель, инфо |
| `app/public/icon.svg` + `app/scripts/make-icons.mjs` | Иконка и генератор всех размеров (PNG 16–1024, maskable, favicon.ico, og.png) |
| `tools/mock-chain.ts` | Локальный «блокчейн» на sandbox + mock toncenter API — для разработки UI без testnet |
| `MODERATION.md` | Разбор: пройдёт ли модерацию Antarctic Wallet |

## Настраиваемые свойства токена

- название, тикер, описание, **логотип on-chain** (сжимается на устройстве до 128×128, хранится в `image_data` — не нужен ни сервер, ни IPFS) или по URL;
- ссылки: сайт, Telegram, X;
- максимальная эмиссия (1 млн … 10 млрд);
- стартовая капитализация и крутизна кривой (цена ×9 / ×25 / ×100 к моменту полной распродажи);
- комиссия автора с каждой сделки 0–5 %;
- лимит покупки за одну сделку (анти-снайпер) 0.5–5 %;
- первая покупка автора (видна всем на графике).

Все параметры неизменяемы после запуска.

## Экономика контракта

Кривая с виртуальными резервами: `x·y = k`, где `x = k/(Vj − S)` (сторона TON), `y = Vj − S` (сторона токена), `k = Vt·Vj`.
Покупка выпускает токены, продажа (burn) сжигает их и платит TON из резерва. Округление всегда в пользу резерва, резерв учитывается отдельно от комиссий. Поэтому каждый держатель может продать в любой момент. Это проверено тестом, в котором все участники продают всё.

| Действие | Сколько TON приложить | Газ фактически (тесты) |
|---|---|---|
| Покупка | сумма + 0.05 (излишек возвращается) | ≈ 0.004 TON |
| Продажа | 0.06 (излишек возвращается) | ≈ 0.002 TON |
| Создание | плата фабрики + 0.1 депозит + 0.1 газ (+ первая покупка) | — |

Комиссии копятся на контракте токена. `claim_fees` может вызвать **кто угодно**: доля автора уходит автору, доля платформы — на фабрику. Владелец фабрики выводит средства командой `withdraw`.

## Быстрый старт

Требуется Node.js 22.

```bash
npm install
```

```bash
npm test
```

```bash
npm run build
```

### 1. Задеплоить фабрику (testnet)

```bash
npx blueprint run deployFactory --testnet --tonconnect
```

Плату за создание и комиссию платформы можно задать через `DEPLOY_FEE=0.3 PLATFORM_FEE_BPS=100` (100 bps = 1 %, максимум 2 %). Позже их можно поменять:

```bash
npx blueprint run setFactoryConfig --testnet --tonconnect
```

Выведенный адрес фабрики впишите в `app/public/floe.config.json → networks.testnet.factories`.

### 2. Настроить мини-апп

`app/public/config.json` — манифест для каталога Antarctic Wallet: впишите `id` из кабинета AW.

`app/public/floe.config.json` — настройки приложения:

| Поле | Значение |
|---|---|
| `network` | `testnet` / `mainnet` |
| `networks.testnet.factories`, `networks.mainnet.factories` | отдельные адреса фабрик для каждой сети (новые версии контрактов = новая фабрика, старые токены продолжают работать) |
| `awMode` | `full` — всё внутри кошелька; `readonly` — внутри AW только каталог и графики, торговля в веб-версии (см. `MODERATION.md`) |
| `networks.<сеть>.toncenterApiKey` | необязательно; без ключа toncenter даёт ~1 запрос/с, с бесплатным ключом — 10/с |
| `networks.<сеть>.toncenterUrl` | необязательно; свой toncenter-v3-совместимый endpoint |
| `hiddenTokens` | адреса токенов, скрытых модерацией оператора |
| `blockedWords` | стоп-слова: токены с ними в названии/описании не показываются |
| `supportUrl`, `sourceUrl` | ссылки на странице «Инфо» |

Модерация без сервера — это коммит в `floe.config.json`, после которого GitHub Pages пересобирается за минуту.

### 3. Локальная разработка

```bash
npm --prefix app install
```

```bash
npm run app:dev
```

Откроется `https://127.0.0.1:5185` (самоподписанный сертификат, AW не принимает `localhost` без точки). В настройках мини-аппа в AW укажите этот URL как App URL.

Без testnet можно поднять локальный блокчейн с демо-данными (3 токена, ~3 дня торгов):

```bash
npm run demo
```

После этого в `floe.config.json → networks.testnet` пропишите выведенный адрес в `factories` и `"toncenterUrl": "http://127.0.0.1:8787/api/v3"`. Верните общие настройки сайта в скрытом экране, если ранее сохраняли локальные адреса.

### 4. GitHub Pages

1. Сделайте эту папку отдельным репозиторием и запушьте в `main`.
2. Settings → Pages → Source: **GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` соберёт `app/` и опубликует его. Тот же workflow прогоняет тесты контрактов. `tonconnect-manifest.json` генерируется с правильным абсолютным URL.
4. URL вида `https://<user>.github.io/<repo>/` укажите в кабинете AW как App URL.

Роутер работает на hash (`#/t/<адрес>`), поэтому `?parentOrigin=` от кошелька сохраняется и 404 на Pages не бывает.

## Что используется из Antarctic Wallet SDK

`@antarctic-wallet/aw-sdk`. Scopes **не запрашиваются**: персональные данные не нужны, а платёжные интенты AW требуют бэкенда с секретом.

- handshake `init()` / `destroy()`, `isInsideWallet()`;
- `startParam` — диплинки `t_<адрес>` открывают токен, `create` — экран создания;
- `backButton` — нативная стрелка «назад» на вложенных экранах;
- `colorScheme` / `themeChanged` + `setBackgroundColor` — тема кошелька;
- `--aw-safe-area-inset-*` — отступы;
- `hapticFeedback` — отклик на выбор, сделки и ошибки;
- `scanQr` — поиск токена по QR и адрес получателя при отправке;
- `shareUrl` (с SDK 0.4.5; в 0.4.4 фолбэк на Web Share / буфер обмена) — «поделиться токеном» и передача ссылки TON Connect во внешний кошелёк.

Подпись транзакций идёт через **TON Connect**. У SDK Antarctic Wallet нет API для подписи TON-транзакций. Если внутри WebView кошелёк не открывается, есть кнопка «Кошелёк не открывается?». Она показывает ссылку подключения (QR, копирование, системное «поделиться»).

## Безопасность и ограничения

- Контракты покрыты тестами, но **не проходили внешний аудит**. Перед mainnet закажите аудит.
- Миграции ликвидности на DEX (STON.fi / DeDust) после распродажи кривой нет: токен торгуется на кривой всегда, переводы свободные, так что DEX-пул может создать любой. Автоматическую миграцию стоит добавить следующим этапом.
- Публичный toncenter без ключа отдаёт ~1 запрос/с. Первая загрузка графика токена с тысячами сделок займёт десятки секунд, дальше история берётся из `localStorage`.
- Урок ZKGRM: у прошлого токена кошелёк блокировал обычные переводы. Для мем-токена это убивает ликвидность и интерес, поэтому здесь кошелёк стандартный TEP-74 без ограничений.
